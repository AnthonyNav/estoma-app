# Recursos visuales

## Fondo del login

- Archivo: `public/images/login-clinic.webp`.
- Origen: imagen generada con la herramienta integrada `image_gen`, convertida a WebP para su entrega web.
- Uso: fondo decorativo de `sign-in.page.scss`; la capa oscura se aplica mediante CSS.
- Referencia: composición clínica de la captura entregada por el usuario. Es un fondo similar generado, no una fotografía de las instalaciones de BUAP.
- Prompt utilizado:

> Create a photorealistic website background asset, not a UI mockup. Landscape 1536x1024. Empty university dental clinic / instrument washing laboratory, cool daylight, pale frosted glass partitions and pale grey cabinetry in upper half, a dental instrument cart with curved grey hoses and a stainless instrument washing station visible at bottom left, softly defocused in the background. Quiet clinical institutional atmosphere, muted petrol grey and cool neutral colors. Center mostly understated empty visual space for a login card that will be added later in HTML. Realistic photograph, no people, no text, no logos, no card, no forms, no overlay. Save generated image for use in project.
