# Archivo de trazabilidad

- backend/: informes recibidos, con el estado de su fecha original.
- frontend/: guías anteriores y revisión local; pueden describir pantallas sustituidas.
- openapi/: snapshots y candidatos históricos.

No usar estos archivos para decidir disponibilidad actual. Consultar [contratos](../contracts/README.md) y [estado](../integration/status.md).
